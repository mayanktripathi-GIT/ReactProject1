# React Best Practices

## ✅ 1. Keep Components Small
Each component should have a single responsibility.

---

## ✅ 2. Use Functional Components
Hooks are simpler and preferred over class components.

---

## ✅ 3. Use Proper Naming
Component names should be meaningful and PascalCase.

---

## ✅ 4. Avoid Prop Drilling
Use Context API or state management.

---

## ✅ 5. Reuse Components
Build reusable UI elements.

---

## ✅ 6. Use Keys in Lists
Always use unique keys.

---

## ✅ 7. Optimize Performance
Use React.memo, useMemo, useCallback.

---

## ✅ 8. Handle Errors Properly
Use error boundaries.

---

## ✅ 9. Keep Logic Separate
Use custom hooks for logic.

---

## ✅ 10. Folder Structure Matters
Organize files properly for scalability.

---

# ✅ Interview Tip

👉 Say:
"Maintainability, readability, and scalability are the core principles."
