# React Folder Structure (Interview Ready)

## ✅ Basic Structure
src/
├── components/      ✅ reusable UI
├── features/        ✅ logic grouped by topic
│   ├── basics
│   ├── hooks
│   └── advanced
├── pages/           ✅ page-level grouping
├── App.jsx          ✅ routing
├── index.js         ✅ entry point

---

## ✅ Explanation

- components/ → reusable UI components
- pages/ → page-level components
- hooks/ → custom hooks
- context/ → global state (Context API)
- services/ → API calls
- utils/ → helper functions
- assets/ → images, styles

---

## ✅ Interview Tip

👉 Always say:
"Structure depends on project size, but separation of concerns is key."
