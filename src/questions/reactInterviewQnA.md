# React Interview Questions & Answers

## ✅ 1. What is React?
React is a JavaScript library for building user interfaces.

---

## ✅ 2. What is JSX?
JSX is a syntax extension that allows writing HTML inside JavaScript.

---

## ✅ 3. What are props?
Props are inputs passed to components.

---

## ✅ 4. What is state?
State is used to manage dynamic data in components.

---

## ✅ 5. What is useEffect?
It handles side effects like API calls.

---

## ✅ 6. What is prop drilling?
Passing props through multiple components unnecessarily.

---

## ✅ 7. What is Context API?
A way to manage global state without prop drilling.

---

## ✅ 8. What is React.memo?
Prevents unnecessary component re-render.

---

## ✅ 9. What is virtual DOM?
A lightweight copy of the DOM used for efficient updates.

---

## ✅ 10. What is code splitting?
Breaking app into smaller chunks for performance.

---

# ✅ Interview Tip

👉 Always explain with:
